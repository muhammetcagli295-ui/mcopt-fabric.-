# McOpt - Fabric Sunucu Optimizasyon Modu (MC 1.20.1)

TPS izleme, otomatik lag tepkisi ve item/XP orb birlestirme yapan bir Fabric modu.

## Ozellikler
- TPS izleyici (kendi olcumu, internal alanlara bagimli degil)
- Otomatik lag tepkisi: tick suresi esigi asilinca randomTickSpeed dusurulur
- Item/XP orb birlestirme
- /mcopt status ve /mcopt reload komutlari

## Derleme
GitHub Actions ile otomatik derlenir (.github/workflows/build.yml).
